# Rajanithi N — Portfolio

A monochrome, editorial portfolio showcasing work across software, data, and applied AI. Built with React and Vite; GSAP/ScrollTrigger and Lenis provide the motion and scroll storytelling. The portfolio has no backend.

## Run locally

```bash
npm install
npm run dev
npm run build
```

## Featured projects

- **CareConnect** — Full-stack emergency blood coordination platform. [Source](https://github.com/rajanithii/CareConnect_AI)
- **ClimatePulse** — Interactive climate-data dashboard. [Live dashboard](https://climate-dashboard-story.streamlit.app/) · [Source](https://github.com/rajanithii/ClimatePulse)
- **CropSure AI** — Hackathon prototype for crop-insurance claim support. [Source](https://github.com/rajanithii/CropSure-AI)

Project descriptions, technologies, and case-study details are maintained in `src/data/projects.js`. ClimatePulse chart values are annual averages computed from the project's bundled dataset across available country/month records; they are not a standard global temperature index.

## Portfolio structure

- `src/components/` — Page sections, project chapters, and case-study overlay
- `src/data/` — Profile, project, achievement, education, and skills content
- `src/animations/` and `src/hooks/` — Scroll, motion, and interaction behavior
- `src/index.css` — Monochrome visual system and responsive styling
